## 目标与不变量

完成ELK构造、真实异步layout、三项元数据查询、公共错误及Python宿主关闭/并发/取消/恢复策略。元数据只暴露实际注册和实现的能力，12/243/8完整参考目录继续单独保留。E07的72个输入、四方向/组件/九项选项、精确结构、输入保留、RNG与既定1e-6/1e-9几何容差不得因调度改变。

当前`async def layout`在调用线程执行CPU工作，现有幂等关闭只是本地标记；它们不能作为真实异步、运行取消、CPU并行或资源释放的证据。固定FakeWorker的terminate异常是参考事实，Python正常关闭是显式宿主设计。两者必须分别记录，不以宽泛异常归一化或额外丢字段让原profile通过。

本轮不扩算法输入域，不提前实现公开端口/标签/层级/其他策略，不提前做py-mermaid集成或正式发布。完整平台/吞吐/峰值内存矩阵仍归E10；本轮必须测实拟声明的任务/队列/关闭/取消与资源边界。

## 独立合同与真实生命周期验证

每个参考样例保存原始JSON字节、constructor/layoutArguments、包/入口SHA、实际argv/cwd/stdout/stderr/exit以及调用前后输入。注册会受进程静态状态影响，缺省、空列表、筛选、非法值及跨实例场景使用独立参考进程；同进程序列另作专门状态污染测试。不同入口或Worker模式的结果不互相代替。

先覆盖构造缺省/空/非法容器、三项元数据查询的类型/字段/顺序/别名/筛选、未知算法与未知端点、已知unsupported与内部故障。查询返回值可被调用方修改时，必须验证下次查询和其他实例未受影响；不能直接把参考12/243/8快照作为当前全支持列表。

生命周期同时具备以下相互独立的证据：

- 成功、失败、排队取消、启动后取消、关闭后提交、重复关闭、失败后成功、多实例与同实例重复调用；图、选项及业务字段复用时保持原值。
- 一次真实CPU布局运行期间事件循环中的独立心跳能推进；实际重叠任务/进程证明声明的并发模型。仅增加`await`、调度一个空任务或测休眠不构成布局调度证据。
- 排队取消验证任务未启动；运行取消需确认实际开始且尚未完成，再验证计算停止及资源回收。可控测试屏障用于确定状态竞争顺序，不能用屏障等待代替真实运行取消；完成优先的竞争结果按冻结合同单列。
- 取消、超时、worker崩溃和关闭后检查实际存活任务/子进程、工作槽位、队列与句柄回收；下一次合法任务可成功，旧任务不能继续写结果、输入或last_trace。
- 并发/队列/图规模界用边界值及超界请求验证；耗时、峰值内存及平台能力保存实测上下文。未实现或无法强制的CPU/内存限制明确保持未验，不能把Future已完成、伪exit0或捕获异常当资源停止证明。

真实官方事实、Python宿主映射、有限调度/资源实测和数学/全算法验收分别报告。E07几何比较继续使用原始请求绑定的policy，候选自造拓扑、改端点、错方向或同值伪结果均应被独立负控检出。
