# 17 批复盘

本批将之前孤立的层级 helper 接入完整 compound 调用：前后处理、层级调度、四个端口处理器和导出均真实执行。新复合图为 300×82，完整几何、日志和业务字段严格一致；原始七项新增形状哈希差异保持可见。独立 DOWN 完整调用也通过，未重跑旧默认或方向矩阵。

Root 完成 transformer/controller、connected compactor、Pair hash 与三种 placer 调用。源码中的 `returnVal` 未定义确实会在内部段抛 ReferenceError，保留该失败及其副作用，而不修补上游数学。新成功对象单独覆盖 ordinary、四向外部扩展及真实调用者；旧 external 身份相关顺序差异不因此关闭。

B 完成真实 Spline P5 和 Final 的控制点、sloppy、链转换。Root 分担其源审和代码审，V 同时处理层级、方向和标签，使一条独审队列不再阻塞所有实现。A 持有 factories/provider 单写权，B 持有 Spline/Polyline，Root 持有共享容器与压缩；审查者不修改实现者文件。

真实完整 SPLINES 首个 logging=true 原请求在日志收集阶段抛空任务名 NPE，首次候选门禁前停止，实际引擎调用为零。随后独立 logging=false 的最小完整请求，原版约 0.229 秒、首候选约 0.444 秒，完整几何严格一致，原始三项新增形状哈希保留；此通过不关闭 logging=true 故障，也不向 Final 伪造 monitor.begin 来绕过上游行为。

本轮纠正的缺口主要是属性默认值和观察合同：共享默认 EnumSet 不能替换为新集合，物理 null 与缺省值要按真实 getter 处理；undefined 省字段不能由比较器随意等同显式 null。Final 的 None 链曾被 truthiness 吞掉，首负控制和修复后受影响对象单独保留；另两处 getter 调用顺序用精确差分复核，未重跑既有曲线组。

针对嵌套形状 `$H` 增加显式保存结果比较规则，先验证整棵形状树再逐上下文调用既有适配 primitive；六个负控制证明业务字段、ID、不合法哈希仍会失败。原始报告和旧浅层投影保留，不能以新比较规则掩盖数值或拓扑差异。

性能继续采用小对象单次原版、新候选首跑和纯保存数据审查。完整 compound 原/候选约 0.250/0.397 秒，DOWN 约 0.237/0.401 秒，Spline 新 prepared P5→Final 约 0.130/0.283 秒；输入和范围不同，不据此声称整体提速比例。后续改进是更早核默认值、失败分支与调用次序，减少后补小叶测试；完整调用优先于继续堆积未经调用的 helper。

下一批优先收口 Spline/Polyline 的实际完整调用、完整高级标签消费者，再推进剩余 Layered 策略与公共 API。MIT 决定继续按实际文件来源落实，源码派生声明不因语法改写批量删除。开发保持变更校验，最终全部功能完成后再全量。
