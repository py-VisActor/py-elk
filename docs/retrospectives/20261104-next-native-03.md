# 通用微布局接入复盘

本批把20项 NodeContext 选项、完整通用微布局和最终 wire 边界接入私有 Session。实际完成4个 MrTree 默认请求与2个有限径向请求的完整 provider 小对照；另保留1个上游非有限结果的 wire 一致性。A 的尺寸数学、完整 standalone process 已有6+3个独立原对象控，后续 side/order、GREEDY 与方向变换也已写入，未将其当完整 layered 管线。

root 负责共享宿主/选项，A 保持 layered 单写，B 完成两种树形核心后准备 force/stress，V 独立核源与新原控。采样改用不可变恢复副本，owner 不必为其它角色采全源 SHA 而停止写代码。常见小检查在一秒内完成；没有据此给出新的整体提速百分比。

两个源差异通过真实原控定位：向量 token 的 Java trim 与入边/出边 compound 条件。每次只修对应分支、重核失败的一例，先前成功报告保留原 SHA。径向的 NaN 也由原真实输出证实，最终 JSON `null` 对照与有效几何分开记录，避免以钳制掩盖上游行为。

原 worker 的 hash 桶碰撞与 mutable defaults 也需真实宿主义务，不能套用旧 LEdge 特例。已落原生 identity 策略、属性缓存及 targeted host 控制。新增受 review SHA 约束的 source JSON 已配置 Git 保留原字节，并实际核9个路径的 Git blob 输入，防 fresh clone 换行导致哈希漂移。

下一批推进 NS 的真实消费者/调度、force/stress、完整属性与递归宿主；基础正式包许可决定仍待落实。全部功能完成后再全量，py-mermaid 集成继续独立后置。
