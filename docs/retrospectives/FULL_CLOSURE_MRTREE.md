MrTree 首败揭示了显式栈移植的风险：原版递归会爆栈的控制环，在移植后可能无限运行。修复只跟踪尚未返回的对象身份，保留合法重复访问；公开 API 及时抛错，正常输入、合法重访和 1500 层链未退化。具体差异见 [ADR 0015](../decisions/0015-mrtree-recursive-cycle.md)。

比较工具的两个数值误报来自缺失 `/result` 前缀，导致既有几何容差没有生效。修正路径后，52 份正常观察按既有规则匹配，原始 strict 差异仍保留；Force 的严格效果指针未过、8 个原版无变化尝试均未升级为效果通过。新增合格几何 ID 为 27，当前总数 73，不能解释为全部 243 个选项语义通过。

新独立算法几何只读取归档，28 个观察中双方各 10 PASS／4 NOT_ASSESSED／0 FAIL，9 个测试捕获 7 个数值破坏负控。DisCo 的 POLYOMINO 可以合法互锁，因此检查跨组件节点矩形分离，不把整个组件 bbox 交叠误报为失败。详细适用条件见 [手册](../INDEPENDENT_ALGORITHM_GEOMETRY.md)。

发现并修正两类交付问题：最终完整校验门禁曾错误要求 E12 已发布，现按功能实现状态放行；旧会话入口叠加互相冲突的状态，现已分成当前入口与历史副本。移动根入口历史 Markdown 曾导致相对链接失败，改为原字节文本归档后结构检查通过。公开 README 的旧九选项说明在首次修复候选后才发现，因此额外做了一次纯元数据重建和双安装；运行文件 208 份不变，Linux 记录继续绑定前一修复 wheel，未冒称新归档执行。

后续改进：候选构建前同时检查 README、公开元数据和新会话入口，再冻结包输入；先列有限声明分母并绑定已有 case/assertion，只有确实缺失的分支才补最小观察。归档、报表和门禁使用固定文件 owner；对会被 Git 换行转换的已绑定字节，先检查 clean/filter 结果。没有测得端到端速度提升比例，不用并行数量代替实际提速证据。

本批不标目标完成。剩余为有限分支／选项角色映射和必要缺口收口，以及真实 PyPI 配置、上传和下载验收；py-mermaid 集成继续后置。
