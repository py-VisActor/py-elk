# 分阶段任务与门禁

主线优先交付独立基础 py-elk 并发布正式 Python 包；py-mermaid 集成是后置独立 I 阶段。
首版范围见 [FIRST_RELEASE_SCOPE](FIRST_RELEASE_SCOPE.md)，实现状态见 [RELEASE_STATUS](RELEASE_STATUS.md)。
实现方法见 [IMPLEMENTATION_PLAN的2A节](IMPLEMENTATION_PLAN.md#2a-python实现策略)，具体执行轮次见 [ITERATION_PLAN](ITERATION_PLAN.md)。
本页M编号定义工作包与验收，E编号安排执行顺序；[机器索引](iteration-plan.json)保存逐轮状态/依赖和M工作包映射，避免另建相互矛盾的完成清单。

| 阶段 | 工作与交付 | 门禁 | 状态 |
| --- | --- | --- | --- |
| M0 项目启动 | 骨架、来源/元数据锁、覆盖账本、开发工具/资料 | bootstrap/负控制、来源校验、诚实范围和本地骨架导入 | 本轮建立，限定结果见状态页 |
| M1 首版契约与 oracle | 来源/许可、断言、JSON/options/API、真实采集/比较 | 首版所需来源/默认值已冻结，参考重采与负控制可信 | E01–E05交付审计/合同/宿主基础及受限DAG source/安装对照；完整断言/API/基础布局门禁待完成 |
| M2 基础 layered | 五阶段/必要 processors、基础拓扑和正交几何 | 原生真实计算，完整结构/几何/坐标差异 | E04–E07实现受限多重图、长边、四方向和多分量；完整域仍待闭环 |
| M3 基础功能闭环 | 独立基础输入/9选项、错误、seed/顺序、API/元数据 | 首版声明分支完整通过，不以 semantic-only 冒充正式兼容 | E09同包有限域和219项行为见证通过，最终屏障见状态页 |
| M4 独立候选验收 | wheel/sdist、类型/例子、平台、生命周期/限制和基本性能 | 同候选干净安装并真实布局，无 Node/JVM/上层项目依赖 | 待实施 |
| M5 正式 Python 包 | 许可/名称/权限、0.1.0 上传、索引与下载复核 | 真实候选可下载、SHA/安装/布局重验，准确公布支持范围 | 待实施 |

| M7 其他算法 | 另外11算法，各自选项/随机/终止/性能 | 每算法独立验收，无同名 fallback | 后续扩展 |
| M8 全量与持续发行 | 全12/243/8、可靠性/平台/规模、后续候选 | 全终态、已声明范围通过、无隐藏 skip | 后续扩展 |

元数据、目录和方法名均不是布局实现。基础0.1.0正式包不等于全量ELK兼容，后续范围保持账本状态。
