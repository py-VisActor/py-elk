上传后使用可重复的只读入口复验：

```shell
python scripts/iteration/pypi_release.py --plan-only
python scripts/iteration/pypi_release.py --version 0.1.0 --expected-wheel ACTUAL_UPLOADED_WHEEL --expected-sdist ACTUAL_UPLOADED_SDIST --out NEW_DIRECTORY
```

该工具不上传文件。它先核公开索引的版本、依赖、文件集合和 SHA，再下载并校验原字节，最后执行隔离安装与真实布局。`--expected-*` 必须是实际已验收并上传的文件；若 GitHub 工作流重新构建了文件，应先取得该次构建的 artifact，不能把本地预备包的 SHA 冒充为重建结果。当前索引实际返回 404，工具明确记录 `PYPI_RELEASE_NOT_AVAILABLE` 和失败状态，没有执行安装或宣称发布成功。

剩余工作是发行与下载复验，不要重新实现算法或重跑已通过的整套数学对照。若修改运行代码，按实际影响重新校验；若修改 `pyproject.toml`、README 或许可等冻结包输入，必须重建候选、更新差异及安装记录。
