# 0.1.1 — 文档与使用入口

本版本将安装、API与资源说明同维护者/AI agent流程分开。用户入口为
[docs/README.md](../README.md)，安装 `python -m pip install py-visactor-elk==0.1.1`。

- 中英文README聚焦安装与最小调用，新增用户指南和API索引。
- 维护、来源核验、旧计划和验收记录集中到开发目录，原始证据不改写。
- PyPI项目链接新增Documentation、Source、Issues与Changelog。
- 相对正式 `v0.1.0`，原生布局实现、依赖与许可保持不变；运行文件仅更新版本字面量。

发行门禁按文档/版本差异选择：核实旧标签的完整运行字节差异，构建一组wheel/sdist，
在Windows与Linux分别安装这两个实际工件，执行既有独立包的模块/元数据、20节点布局
与MrTree异常代表检查。全部验证完成后才由Trusted Publisher上传同组文件，并回读
PyPI实际元数据、两个下载SHA与安装结果。旧版本与旧标签保留，不重跑无关算法全量。

实际上传/回读结果另记在本目录的 `0.1.1-publication.json`；只有该记录及远端实际结果
才能表明发布成功。本文的发布准备不等于已上传。
