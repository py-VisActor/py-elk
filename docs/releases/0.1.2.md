# py-visactor-elk 0.1.2

This release documents macOS installation and adds isolated wheel and source-distribution layout checks for Apple Silicon and Intel. The same pure Python distribution supports Python 3.11 and later across macOS, Windows and Linux.

```sh
python -m pip install py-visactor-elk==0.1.2
```

Run layout from a saved Python script and protect the entry point with `if __name__ == "__main__":` so the layout worker can start with `spawn`.
