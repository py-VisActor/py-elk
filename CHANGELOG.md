# Changelog

## 0.1.1

- Separate installation/API documentation from maintainer and AI agent workflows.
- Add a user documentation index, usage/API guides and clear historical-document navigation.
- Publish Documentation, Source, Issues and Changelog project URLs.
- Layout implementation, runtime dependencies and supported Python versions are unchanged;
  only the package version literal changes in the runtime payload.

## 0.1.0

- Published as `py-visactor-elk`; Python imports remain `pyelk`.
- Native Python layout with async `ELK`, isolated worker lifecycle and metadata queries.
- Default catalogue: 12 algorithms, 243 options, 8 categories; these are registration counts,
  not a claim of exhaustive semantic or coordinate compatibility.
- Includes the MrTree recursive-cycle termination repair.
