# ADR0014：保存结果中嵌套形状的生成 hash

2026-11-04。仅用于新的显式保存结果比较，不修改 ADR0001 的平面 v1 profile、原始 strict 或产品代码。

17 批唯一新完整 compound 原版请求 `219cf9b6…`、结果 `ef19bb62…`，与实际原生结果 `d5c093a6…` 的差异仅为上游新增的七个 `$H`：root、两个直接子节点、四个孙节点。旧浅层 primitive 只处理前三个，因此原比较仍为失败，四个嵌套差异保留。几何及完整日志无差异，但该事实不能自动放宽比较规则。

新增 `check_layered_saved.py --project-reference-hierarchy-shape-hashes`。先核整棵 `children` 树的节点身份、数组类型、长度和逐项位置；任一不符即停止投影。随后在各个实际子图上下文调用已有 primitive，沿用其全部条件：原输入无 `$H`、上游值是有限整数而非布尔值、原生没有补造同名字段、原有字段必须在两边原样保留。每项保留具体路径、上游值和原规则，并附 `GWT-SHAPE-HASH-HIERARCHY-01` 上下文标记。

遍历仅沿模型节点的 `children`，不遍历任意业务字典、边、端口或标签。现有业务中的 `$H:false`、`$H:0` 继续严格比较；不全局删除同名键、不排序、不改坐标容差、不伪造引擎 hash。默认仍无投影，旧 `--project-reference-shape-hashes` 仍只处理原来的浅层范围，两种选项互斥。

新报告同时保留 rawStrict、逐项 adaptations、violations 和投影后的完整严格差异。该工具只核已经保存的 JSON、请求指纹与锁定的 stock 参考身份，不证明实际执行版本、调用方输入保留、完整算法、安装或发行验收；这些仍须读实际运行和独审收据。不得用本次新工具覆盖原报告或把旧实际执行重绑新源码。
